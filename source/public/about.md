# About
Welcome to plasmatoroid.net, a cool website with cool stuff on it!
I update this site every so often, so come back here once in a while to
see more cool stuff!

## About Will
My name is Will, and I am the sole author of this site. I am currently a full-time student and I live in the USA in the state of [Oregon][4].

There is currently no way for you to contact me. Who are you? Some kind of internet stalker!? A bot? I get too much spam mail as it is. I do plan to add a comments system to this site eventually, but for now, you'll just have to wait.

## Technical Details
This site is currently hosted on a [Raspberry Pi 5][1] running [NGINX][2]. This site uses no frameworks; all the server code powering this site is written in [C][6] by me, and all the client-side code is plain-old [JavaScript][7]. I register my domain names with [Porkbun][3]. The source code for this site will be available on Github, eventually.
